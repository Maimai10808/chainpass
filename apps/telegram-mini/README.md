# ChainPass Telegram Mini App

Experimental Vite/React scaffold, not a complete ChainPass client.

```bash
pnpm --filter @chainpass/telegram-mini dev
pnpm --filter @chainpass/telegram-mini build
pnpm --filter @chainpass/telegram-mini typecheck
pnpm --filter @chainpass/telegram-mini lint
```

The SDK dependency is available for future Telegram-hosted integration. The current
welcome page also works in a regular browser; no fake Telegram environment, login,
payment, wallet, or API access is implemented.
